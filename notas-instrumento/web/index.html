    Añadir una canción
    1. Sube el MP3 a la carpeta notas-instrumento/canciones de GitHub (arrástralo y pulsa «Commit changes»).
    2. GitHub la analiza solo. Tarda unos minutos; puedes verlo en Actions.
    3. Cuando termine, recarga esta página.

    Sin subir el archivo al repositorio: en Actions → Notas de un instrumento → Run workflow pega un enlace de descarga (Dropbox, Google Drive compartido con «cualquiera con el enlace»...) y un título. Así la canción original no queda guardada en el repositorio.
