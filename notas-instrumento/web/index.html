Canciones

    Todavía no hay ninguna canción.

    Añadir una canción desde un archivo
    1. Sube el MP3 a la carpeta notas-instrumento/canciones de GitHub (arrástralo y pulsa «Commit changes»).
    2. GitHub la analiza solo. Tarda unos minutos; puedes verlo en Actions.
    3. Cuando termine, recarga esta página.

    Sin subir el archivo al repositorio: en Actions → Notas de un instrumento → Run workflow pega un enlace de descarga (Dropbox, Google Drive compartido con «cualquiera con el enlace»...) y un título. Así la canción original no queda guardada en el repositorio (el resultado sí se publica).

    Conectar con GitHub (solo la primera vez)

    Para mandar la grabación a GitHub, que es quien la analiza, este móvil necesita un token: una clave de acceso limitada a este repositorio. Se guarda solo en este móvil.

    1. Abre crear un token en GitHub.
    2. Nombre: el que quieras (p. ej. «Notas móvil»). Caducidad: la que prefieras.
    3. Repository access → Only select repositories → elige este repositorio.
    4. Permissions → Contents: Read and write. Opcional: Actions: Read-only (para ver el progreso).
