# Canciones por procesar

Sube aquí los audios (MP3, WAV, FLAC, OGG, M4A). GitHub Actions los analiza, publica el
resultado en `../web/` y **borra el audio de esta carpeta** al terminar.

Ojo: aunque se borre, el audio sigue en el historial de git. Si no quieres que la canción
original quede en el repositorio, usa el enlace de descarga (Actions → Notas de un
instrumento → Run workflow). Ver `../README.md`.
